# 文章の判断軸

本文を書く前と、推敲するときに読む。型に当てはめるための資料ではなく、「どちらの方向を選ぶか」を決めるための資料。すべてを一つの記事に入れる必要はない。記事の目的、確認できた事実、読み手が理解しやすい順番を優先する。

自然な文章は、言い回しを似せても再現できない。語彙よりも、何を入口に選び、どの事実を残し、どこまで説明し、読者にどれだけ余白を渡すかという判断を合わせる。

## 基本姿勢

書き手の正解を押しつけるのではなく、必要な情報を明確に伝えたうえで、一緒に考えられる余地を残す。大声で励ますのではなく、隣に座って静かに話すように書く。説教しない、上から教えない、正解を押しつけない。

読者からの相談に答える記事では、特定の言い回しを避けるより、書き手の立ち位置を整えることを優先する。読者を「困っている人」と決めつけず、上から許可したり判定したりせず、選択肢や考え方を横に置くように書く。迷ったら次の3つを確認する。

- これは読者の感覚を勝手に決めていないか
- 書き手が「許可する」言い方になっていないか
- 選ぶ余地を残せているか

## 3つの柱

| 柱 | 内容 |
|---|---|
| 現実から始める | 出来事、素材、書き手の経験など、読み手と共有できるものから語る |
| 自分の理由を語る | 一般論ではなく、書き手自身がどう考え、何を選んだかを書く |
| 押しつけない | 正解を提示せず、読者が考える余白を残す |

## 自然な文章をつくるための判断軸

自然さは、口語に寄せることや、柔らかい言葉を増やすことではない。読み手が途中で立ち止まらず、書き手がなぜその話をしているのかを追える状態を指す。同時に、書き手が実際に話すときの間合い、確信の強さ、言い切らずに考えている部分も、意味の一部として扱う。

### 具体から意味へ進む

まず出来事、行動、素材、言葉など、読み手が同じものを思い浮かべられる事実を置く。意味や考えは、その事実を受けて書く。抽象的な価値を先に宣言してあとから例を添えるより、読み手が事実から同じ意味へたどり着ける順番を選ぶ。

### 書き手の考えが動いた順番を守る

結論をきれいに見せるために、迷いや経緯を消しすぎない。ただし時系列をすべて並べるのではなく、現在の考えに至るうえで必要な変化だけを残す。「当初は何が見えていなかったか」「何をきっかけに見方が変わったか」がわかると、文章は説明ではなく物語として読める。

### 読者の感情を作らない

共感は、読者の気持ちを言い当てることではない。実際にありそうな状況や、自分自身の経験を差し出し、読者が自分との重なりを判断できるようにする。広く共有されていると確認できない違和感を「多くの人の悩み」として始めたり、読者が感じるはずの感動を先回りして説明したりしない。

### 事実の温度と大きさを変えない

印象的にするために、出来事や感情を実際より劇的にしない。うれしかったことを人生を変えた出来事へ、迷ったことを深い苦悩へ置き換えない。曖昧さ、ためらい、意外だったこと、少し矛盾して見える感情も、経験を正確に伝えるために必要なら残す。

事実を整えるときは、読みやすさだけでなく、出来事の規模、感情の強さ、書き手の確信度が変わっていないかを確認する。もっともらしい情景や心理を補うことより、本人が実際に覚えている範囲を守る。

### 具体性は、判断の根拠を共有するために使う

具体的に書く目的は、情報量を増やすことではない。書き手がなぜそう考え、何を選んだのかを、読者が無理なく追えるだけの根拠を共有するために使う。必要な具体性は記事によって違う。出来事や条件、比較したもの、交わした言葉、身体感覚、数字など、判断の根拠になるものを選ぶ。細部を足すときは「これによって書き手の判断が理解しやすくなるか」を基準にする。

### 変化の主語と役割を分ける

何かが変わった経緯を書くとき、外部の環境、きっかけ、書き手の受け取り方、選択したこと、実際に行ったこと、結果を、一つの主語にまとめない。それぞれが変化の中でどの役割を持ったのかが伝わるようにする。

外部環境だけで結果を説明すると、書き手が何を考えて動いたのかが消える。反対に、すべてを自分の成果として語ると、条件や他者から受けた影響が消える。原因を一つに決めず、関わった主体と作用の関係を正しい大きさで書く。

### 書き手の声を整えすぎない

推敲では誤解や読みにくさを直すが、文章を均質に整えることは目的にしない。書き手が「そう思う」と話していることを一般的な事実へ変えたり、会話では自然な言い回しを硬い説明文へ統一したりすると、内容が同じでも書き手の存在が薄くなる。

言葉の重複や話し言葉も、単なる癖なのか、考えながら話す呼吸や強調として働いているのかを見て判断する。洗練された表現より、誰がどの立場から話しているかが伝わる表現を優先する。

### 平易さを、浅さと考えない

言い換えられる抽象語を重ねず、何をしたのか、何が違うのかを普通の言葉で書く。比喩や余韻のある表現は、意味を短く深く伝えるときに使い、文章を「らしく」見せるためだけには使わない。詩的な一文がなくても、選んだ事実と順番から書き手らしさは伝わる。

### 一つの段落を、一つの前進にする

段落ごとに、読み手の理解が一段だけ進むようにする。同じ意味を言葉を変えて繰り返したり、説明・感想・案内を一度に担わせたりしない。短い文と長い文を機械的に混ぜるのではなく、内容の切れ目で文を切り、声に出したときに主語と着地点を見失わない長さに整える。

画面で読む記事では、一つの文を一つの段落として置くことも選択肢になる。すべてを短く切るのではなく、受け取ってほしい箇所と続けて読んでほしい箇所を分け、話す間合いが見える余白をつくる。

### 主軸以外の事実は、消す前に置き場所を考える

焦点を明確にすることと、読者の判断に必要な情報を削ることは別。主題を支える事実、現在の限界、他との違い、利用前に知ってほしい条件は、導入や中心部分に置くと話が散る場合でも、案内や結論の前では役立つことがある。

主軸から外れる情報を見つけたら、「不要か」ではなく「読者がどの段階で必要とするか」を考える。

### タイトルの役割

タイトルは、何について書かれた記事かを具体的に伝え、検索する人の言葉と接点を持たせる。作品やサービスの紹介では、既に知っている人だけに向けた制作理由になっていないかも確認する。読者が何を形にしたいのか、どんなときに必要なのかを入口にし、造形や加工の説明はその意味を理解するための具体例としてつなぐ。シリーズ全体の想いと個別の作品の事実は、対象を明示して混同しない。

## 導入で先に確認すること

導入の役割は雰囲気をつくることではなく、読者が「何の話を、なぜ今読むのか」をつかめるようにすること。そのテーマの価値が表れる具体的な場面や、記事を書く理由になった出来事から入る。

読者の状況から始める場合は、その感覚が誰にでも当てはまるように広げない。書き手の行動や制作上の出来事が最もわかりやすい入口なら、共感を演出する前置きを足さず、事実から始める。導入の形は記事ごとに変えてよい。

## 抽象的な考えを伝える順番

考えは単独で説明するより、書き手が見た事実や、素材・技法・お客様とのやり取りから立ち上げる。読み手が具体的なものを追った先で、その事実を書き手がどう受け取ったのかを示す。

抽象語を避けること自体が目的ではない。抽象語が、前に書かれた具体的な内容をまとめ、新しい見方を与えているかを確認する。具体的な説明へ戻せない言葉や、別の人の記事にもそのまま当てはまる言葉が続くときは、書き手の主語、実際に選んだこと、目に見える変化へ戻る。

短い文章でも同じ。余韻をつくるために情報を隠さず、何の話かがわかる最小限の具体性を残したうえで、説明しきらない部分をつくる。

## 事実と判断の距離

確認できたこと、書き手が経験したこと、そこから考えたことを混ぜず、それぞれの距離が伝わるように書く。未確認の部分を、流れをよくするために推測で補わない。適合性、安全性、可否、個別の事情に関わる内容では、一般的に言えることと、その人について判断できることを分ける。

押しつけないことは、曖昧にすることではない。確認できた条件や限界、次に取れる行動は明確に伝える。そのうえで、価値の受け取り方や選択を読者へ委ねる。

## 推敲時に見ること

AIで下書きした文章は、意味が通っていても、語順や段落の呼吸が硬くなる。最終確認では、内容を増やすより先に、読み手が自然に追える流れになっているかを見る。

| 見る観点 | 調整の方向 |
|---|---|
| 文の長さ | 一文に複数の役割を詰め込まず、列挙・説明・気づきを分けて読ませる |
| 敬意の距離 | 読者や顧客の選び方は、一般化しすぎず、ひとりひとりの選択として扱う |
| 技術説明 | 仕組みを正確に書き、記事の目的に必要な場合だけ、書き手がそれを選んだ理由へつなぐ |
| 考えへの接続 | 抽象語だけで終えず、使う時間、選び直す機会、今の自分を見つめる場面へ落とす |
| 見出し | 余韻だけで曖昧にせず、その章で何が起きるかが自然に伝わる言葉にする |

レビューで直すときは、表現を一律に禁止・許可しない。その記事で読者がどこから入り、どの順番なら自然に受け取れるかを基準にする。

## 避けたい方向

| 方向 | 理由 |
|---|---|
| 説教する | 読者が自分の感覚で考える余白がなくなる |
| 義務にする | 話が重く窮屈に聞こえる |
| 根拠なく励ます | 読者の不安や迷いを軽く扱っているように見える |
| 比較で強く売る | 静かな価値観より、広告的な主張が前に出る |
| 希少性だけで煽る | 背景や込めた意味が薄くなる |
| 調子を上げすぎる | 長文記事では、読者が落ち着いて考える空気を壊しやすい |

長文記事では感嘆符を原則使わない。使っても3個以内。

</PROSE_VECTOR>
