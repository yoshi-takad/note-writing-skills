# 記事案テンプレート

記事案をまとめるときの形式。作業フォルダがあるなら `記事案.md` として保存する。6ステップの要点は、書き手に見せて確認をもらうために先に出す。noteに貼るのは「本文(note投稿用)」の範囲だけ。

```markdown
# 記事案: [仮タイトル]

## メタ情報

- 記事の種類: 想い・価値観 / 素材や技法 / 作品・サービスのコンセプト / 制作背景 / お客様との接点
- 想定読者(今、〇〇な人):
- 読後の変化(読者の感じ方がどう変わるか):
- 検索されたいキーワード:
- 推定文字数:
- ハッシュタグ案(大きな言葉・中くらい・ニッチの3層):
- 表記ルール(名称、一人称、避ける表現):

## 一次情報

書き手から聞いた範囲だけを書く。

- 原体験・きっかけ:
- 制作や判断の過程:
- お客様の声・やり取り:
- 参照した資料・写真:
- 事実確認が必要な点:
- 足りない情報(書き手に質問する):

## 6ステップ

### 1. 伝えたいこと

→

### 2. ポイント

1.
2.
3.

### 3. 理由・背景

| ポイント | 背景・理由・経験(書き手の言葉) |
|---|---|
|  |  |

### 4. 伝えたい人

→ 今、                              な人

### 5. 補足・フォロー

- 「自分には関係ない」と感じそうなこと:
- 抽象的すぎて補足が必要なこと:
- 書き手は当然だが読者は共有していない前提:
- 「でも自分は…」と引っかかりそうなこと:
- 押しつけに感じそうなこと:

### 6. 順番

この順番にする理由:

1.
2.
3.

## タイトル案

| # | タイトル | 文字数 | 狙い |
|---|---|---:|---|
| 1 |  |  |  |
| 2 |  |  |  |
| 3 |  |  |  |
| 4 |  |  |  |
| 5 |  |  |  |

推奨:

## 本文(note投稿用)

[ここからnoteに貼る本文]



[ここまで]

## レビュー結果

- 読者として読む:
- 事実の確認(正確 / 要修正 / 要確認):
- トーン:
- 反映したこと・保留したこと:
- AIらしさの除去: yomiyasu で実施 / 簡易チェックで実施
```
